# Pulsey Client (build-on-GitHub edition)

Upload this folder's contents to a new GitHub repository. GitHub builds the jar for you:
Actions tab -> latest run -> Artifacts -> pulsey-client-jar.

Install: Fabric Loader for 1.21.11 + Fabric API + the jar in your mods folder.
In game: Right Shift = ClickGUI, V = Freecam (singleplayer only).
